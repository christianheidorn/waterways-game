# Roadmap

Every phase follows one rule: **UI ↔ MCP parity**. Anything added to the editor ships with its MCP tool, tests
and docs (docs/MCP.md) in the same phase, so AI agents can do everything a user can.

| Phase                                  | Scope                                                                                                                                                                                                                                                                                                                                             | Status   |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| **1. Collision**                       | Colliders for foliage types (trunk / bounds / custom / none, defaults per kind) and prop models (auto hull or boxes, optional mesh); spatial lookup; player capsule collision with sliding and step-up; camera collision; walk mode in the editor; a Collision debug view; MCP: collision settings, `sample_collision`, debug view in screenshots | **Done** |
| **2. MCP parity**                      | Audit of every editor / studio control against MCP (matrix in docs/MCP.md) and the missing tools: edit placed props, graphics menu, view modes, photo mode, play / walk, spawn direction, character settings, thumbnails, library management, requests from the agent                                                                             | **Done** |
| **3. Building I**                      | Editable path / road splines (road bed, banking, paint, clear foliage, blend); rivers as editable splines; landscape stamps; prop snapping (grid, slope, edge-to-edge, along a path); MCP for all                                                                                                                                                 | **Done** |
| **4. Building II**                     | Layers, materials, biomes and weather editable in the editor; undo history panel; periodic automatic snapshots; map templates and maps from a description; MCP for all                                                                                                                                                                            | **Done** |
| **5. Performance**                     | Two-phase occlusion culling; dynamic resolution targeting the display refresh; KTX2 / Basis textures and compressed meshes (with conversion of existing assets); octahedral impostors; editor work in web workers on WebGL; profile comparisons in MCP                                                                                            | **Done** |
| **6. Looks I: motion**                 | Dithered LOD crossfades; travelling wind gusts; grass bending around the player; cloud shadows; light shafts in fog; MCP settings                                                                                                                                                                                                                 | **Done** |
| **7. Looks II: surfaces and water**    | Large-scale colour variation for PBR terrain materials; shoreline foam, flowing rivers, caustics; footprints in snow, puddles in hollows; MCP settings                                                                                                                                                                                            | **Done** |
| **8. Looks III: bounce light**         | Irradiance grid (bounce light), updated after edits; MCP strength setting and debug view                                                                                                                                                                                                                                                          | **Done** |
| **9. Performance quick wins**          | Retina-aware render scale with temporal upscaling, cheaper water reflection pass, smooth grass thinning with distance, staggered low-rate updates, coarse off-screen group culling, editor work in workers on WebGPU                                                                                                                              | **Done** |
| **10. Water bodies and waves**         | Connected water bodies with per-body settings; GPU FFT wind waves (fetch-limited, whitecaps) on WebGPU; camera-centred fine water mesh; subsurface glow, glints, catspaws; MCP `edit_water_body`                                                                                                                                                  | **Done** |
| **11. Beaches**                        | Shore distance field; shoaling, refracting, breaking waves; swash run-up and wet sand; Surf brush and per-body surf settings; lapping audio; MCP `paint_surf`                                                                                                                                                                                     | **Done** |
| **12. Water interaction**              | GPU ripple simulation around the player (footsteps, wading, objects, wakes); wading slowdown, splashes, wet character; MCP                                                                                                                                                                                                                        | Planned  |
| **13. Swimming, underwater, floating** | Swimming; underwater fog, caustics, Snell's window, muffled audio; buoyant props drifting with currents; plants pushed by water and player; MCP                                                                                                                                                                                                   | Planned  |

Further out (not scheduled): streaming and multi-tile worlds beyond 1025², terrain holes, gameplay entities
(NPCs, boats, quests), a build / publish pipeline for standalone games.
