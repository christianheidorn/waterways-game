# Roadmap

Every phase follows one rule: **UI ↔ MCP parity**. Anything added to the editor ships with its MCP tool, tests
and docs (docs/MCP.md) in the same phase, so AI agents can do everything a user can.

| Phase                               | Scope                                                                                                                                                                                                                                                                                                                                             | Status      |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| **1. Collision**                    | Colliders for foliage types (trunk / bounds / custom / none, defaults per kind) and prop models (auto hull or boxes, optional mesh); spatial lookup; player capsule collision with sliding and step-up; camera collision; walk mode in the editor; a Collision debug view; MCP: collision settings, `sample_collision`, debug view in screenshots | In progress |
| **2. MCP parity**                   | Audit of every editor / studio control against MCP (matrix in docs/MCP.md) and the missing tools: edit placed props, graphics menu, view modes, photo mode, play / walk, spawn direction, character settings, thumbnails, library management, requests from the agent                                                                             | **Done**    |
| **3. Building I**                   | Editable path / road splines (road bed, banking, paint, clear foliage, blend); rivers as editable splines; landscape stamps; prop snapping (grid, slope, edge-to-edge, along a path); MCP for all                                                                                                                                                 | Planned     |
| **4. Building II**                  | Layers, materials, biomes and weather editable in the editor; undo history panel; periodic automatic snapshots; map templates and maps from a description; MCP for all                                                                                                                                                                            | **Done**    |
| **5. Performance**                  | Two-phase occlusion culling; dynamic resolution targeting the display refresh; KTX2 / Basis textures and compressed meshes (with conversion of existing assets); octahedral impostors; editor work in web workers on WebGL; profile comparisons in MCP                                                                                            | Planned     |
| **6. Looks I: motion**              | Dithered LOD crossfades; travelling wind gusts; grass bending around the player; cloud shadows; light shafts in fog; MCP settings                                                                                                                                                                                                                 | Planned     |
| **7. Looks II: surfaces and water** | Large-scale colour variation for PBR terrain materials; shoreline foam, flowing rivers, caustics; footprints in snow, puddles in hollows; MCP settings                                                                                                                                                                                            | Planned     |
| **8. Looks III: bounce light**      | Irradiance grid (bounce light), updated after edits; MCP strength setting and debug view                                                                                                                                                                                                                                                          | Planned     |

Further out (not scheduled): streaming and multi-tile worlds beyond 1025², terrain holes, gameplay entities
(NPCs, boats, quests), a build / publish pipeline for standalone games.
